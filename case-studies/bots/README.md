<summary><b>Cara Menambahkan Project Kamu ke Sini (Klik untuk membuka)</b></summary>
<br>

> **PENTING: Pastikan Kamu Adalah Member CodeSphred!**
> Jika kamu belum tergabung dalam organisasi GitHub CodeSphred, silakan hubungi atau kirim username GitHub kamu ke **Owner/Admin** terlebih dahulu agar bisa diundang masuk ke dalam organisasi.

**Langkah-langkah menambahkan project:**
1. **Buat Folder Baru**: Buat folder dengan nama project kamu beserta username di dalam direktori ini (contoh: `discord-music-bot-johndoe`).
2. **Tambahkan File**: Masukkan *source code*, *assets*, atau dokumen pendukung lainnya ke dalam folder tersebut.
3. **Buat README**: **(WAJIB)** Buat file `README.md` di dalam folder project kamu. Sangat disarankan untuk menyalin template dari [`../../templates/PROJECT_README.md`](../../templates/PROJECT_README.md) agar seragam dan rapi.
4. **Update Daftar Project**: Jangan lupa tambahkan project kamu ke baris baru pada tabel **Daftar Project** di atas sesuai urutan nomornya.
