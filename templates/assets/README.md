# 📸 Assets Folder

Simpan gambar *screenshot*, GIF demo, logo, atau diagram arsitektur project kamu di dalam folder `assets/` ini.

**Contoh Struktur:**
```text
my-project/
├── assets/
│   ├── screenshot-1.png
│   ├── demo.gif
│   └── architecture.jpg
├── src/
└── README.md
```

Nantinya, kamu bisa memanggil gambar tersebut di dalam `README.md` kamu dengan cara:
`![Screenshot Aplikasi](./assets/screenshot-1.png)`
