Tujuan utama dari repo ini adalah untuk **belajar dari project nyata** dan **berbagi workflow serta code structure** antar member.

## Struktur Repository

Repository ini didesain agar rapi dan mudah di-scale:

```text
community-case-studies/
├── .github/                # GitHub workflows & templates
├── templates/              # Template README untuk project
├── case-studies/           # Folder utama untuk seluruh submission
│   ├── web-development/    # Kategori project
│   │   └── <project-name>-<username>/  # Setiap project gabung dengan nama user
│   ├── automation/
│   ├── python/
│   ├── ui-ux/
│   ├── bots/
│   └── showcase/
```

## Kategori Project
Kamu bisa memasukkan projectmu ke salah satu kategori berikut di dalam folder usermu:
- **web-development**: Website, web app, landing page, API.
- **automation**: Script automasi tugas sehari-hari, web scraping.
- **python**: Eksperimen Python, data science, analisis.
- **ui-ux**: Case study desain UI/UX, prototype Figma.
- **bots**: Discord bot, Telegram bot, Twitter bot.
- **showcase**: Project unik lainnya yang tidak masuk kategori di atas.

## Cara Berkontribusi
Ingin memamerkan projectmu? Sangat mudah!
Silakan baca panduan lengkapnya di [CONTRIBUTING.md](CONTRIBUTING.md).

## Code of Conduct
- Saling menghargai karya member lain.
- Dilarang mengupload kode yang berbahaya (malware/virus).
- Pastikan tidak mengupload data sensitif (`.env`, API Keys, Password).
